Build MyVpn 隐私政策 / Privacy Policy

Last updated: 2026-11-22

1. 零账号与零流量日志 / Zero Accounts & Zero Traffic Logs

Build MyVpn 是一款开源自建 VPN 客户端，不提供用户注册系统，不运营任何公共代理服务器，也不收集、记录或上传你的浏览记录、DNS 查询或代理流量。

2. SSH 凭据“用后即焚” / Use-and-Discard SSH Credentials

你在添加 VPS 时输入的 SSH 密码仅在部署期间驻留内存，部署结束后立即从内存擦除，永不落盘存储或发送至任何第三方服务器。

3. 本地加密存储 / Local Hardware-Backed Encryption

部署完成后生成的节点连接密钥仅保存在本机应用私有目录，并使用 Android Keystore 硬件级 AES-256-GCM 加密保护。

4. 静态配置与规则更新 / Static Config & Rules

应用仅请求公开静态规则清单（.srs）与展示配置（monetization.json），不集成任何闭源追踪广告 SDK。
