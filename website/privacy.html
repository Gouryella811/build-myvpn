Build MyVpn 隐私政策

最后更新：2026-11-22

1. 零账号与零流量日志

Build MyVpn 是一款开源自建 VPN 客户端，不提供用户注册系统，不运营任何公共代理服务器，也不收集、记录或上传你的浏览记录、DNS 查询或代理流量。

2. SSH 凭据“用后即焚”

你在添加 VPS 时输入的 SSH 密码仅在部署期间驻留内存，用于向你自己的 VPS 安装 sing-box 服务，部署结束后立即从内存擦除，永不落盘存储或发送至任何第三方服务器。

3. 本地加密存储

部署完成后生成的节点连接密钥仅保存在你手机的本地应用私有目录，并使用 Android Keystore 硬件级 AES-256-GCM 加密保护。

4. 远程配置与规则更新

应用仅在必要时请求公开的静态规则清单（.srs 分流规则）与赞助/推荐配置文件（monetization.json），不包含任何闭源广告追踪 SDK 或设备指纹采集。
