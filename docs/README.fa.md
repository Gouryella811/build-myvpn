## Build MyVpn چیست؟

**Build MyVpn** یک اپلیکیشن رایگان و متن‌باز اندروید برای راه‌اندازی و استفاده از VPN شخصی روی سرور مجازی (VPS) خودتان است.

بدون نیاز به دانش لینوکس، اجرای دستورات خط فرمان یا تنظیم دستی گواهی SSL، کافی است آدرس VPS و اطلاعات ورود SSH را وارد کنید. برنامه به‌صورت خودکار سرور را پیکربندی می‌کند، رمز SSH را بلافاصله از حافظه پاک می‌کند و امکان اتصال با یک لمس را فراهم می‌آورد.

## مناسب چه کسانی است؟

- کاربرانی که VPS شخصی دارند و می‌خواهند بدون یادگیری لینوکس و تنظیمات پیچیده، VPN اختصاصی خود را داشته باشند.
- افرادی که به دنبال ابزار پاک، بدون حساب کاربری، بدون سرورهای اشتراکی عمومی و بدون ثبت گزارش ترافیک هستند.
- هر کسی که می‌خواهد یک یا چند سرور شخصی را به‌سادگی از طریق اندروید راه‌اندازی و مدیریت کند.

## ویژگی‌های کلیدی

- **راه‌اندازی خودکار با یک لمس** — نصب و پیکربندی خودکار `VLESS + REALITY` (پورت TCP 443) و شتاب‌دهی TCP BBR روی VPS بدون نیاز به دامنه یا گواهی دستی؛ همراه با گزینه اختیاری `Hysteria2` (پورت UDP 443).
- **حریم خصوصی و متن‌باز** — بدون ثبت‌نام، بدون سرور واسط و بدون SDKهای تبلیغاتی بسته‌متن. رمز SSH فقط در زمان نصب استفاده و بلافاصله پاک می‌شود.
- **استفاده ساده روزمره** — اتصال سریع، نمایش لحظه‌ای سرعت دانلود/آپلود، تست پینگ، وضعیت آنلاین و میزان مصرف هر سرور، و مسیریابی هوشمند منطقه‌ای.
- **پشتیبانی از ۱۷ زبان** — دارای رابط کاربری در ۱۷ زبان از جمله پشتیبانی کامل از راست‌به‌چپ (RTL).

## شروع سریع

1. آخرین نسخه Android APK را از **[GitHub Releases](https://github.com/Gouryella811/build-myvpn/releases/latest)** دانلود و نصب کنید.
2. وارد **Build MyVpn** شوید، به بخش **سرورها ← افزودن VPS** بروید، آدرس سرور و اطلاعات SSH را وارد کرده و دکمه نصب را بزنید.
3. به صفحه **اتصال** برگردید و برای شروع روی دکمه اتصال ضربه بزنید.
