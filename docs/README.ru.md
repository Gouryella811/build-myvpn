## Что такое Build MyVpn?

**Build MyVpn** — это бесплатный Android-клиент с открытым исходным кодом для быстрой настройки и использования личного VPN на вашем собственном VPS.

Вам не нужно знать Linux, работать с консолью или вручную настраивать сертификаты. Просто введите IP-адрес сервера и данные SSH — приложение само настроит сервер, сразу удалит пароль SSH из памяти и подключится в одно касание.

## Для кого этот инструмент?

- Для пользователей, у которых есть собственный VPS и которым нужен личный VPN без изучения Linux и сложных настроек.
- Для тех, кто не хочет зависеть от общих серверов, регистрации аккаунтов и скрытого сбора данных.
- Для всех, кому нужно простое и открытое приложение на Android для управления одним или несколькими личными VPS.

## Основные возможности

- **Автоматическая установка в один клик** — Автоматически настраивает `VLESS + REALITY` (TCP 443) и ускорение TCP BBR на вашем VPS без домена и ручных сертификатов. При необходимости доступен `Hysteria2` (UDP 443).
- **Приватность и открытый код** — Без аккаунтов, без сторонних серверов и без закрытых рекламных SDK. Пароли SSH удаляются из памяти сразу после установки и нигде не сохраняются.
- **Удобство каждый день** — Подключение в одно касание, скорость в реальном времени, проверка задержки, статус доступности и учёт трафика по каждому серверу, умная маршрутизация.
- **17 языков интерфейса** — Поддержка 17 языков, включая полноценный интерфейс с направлением письма справа налево (RTL).

## Быстрый старт

1. Скачайте и установите актуальный Android APK на странице **[GitHub Releases](https://github.com/Gouryella811/build-myvpn/releases/latest)**.
2. Откройте **Build MyVpn**, перейдите в **Серверы → Добавить VPS**, введите адрес и данные SSH и нажмите **Установить**.
3. Перейдите на вкладку **Подключение** и нажмите кнопку запуска.
